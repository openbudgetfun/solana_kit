# Track `@solana-mobile/mobile-wallet-adapter-protocol-kit` `3.0.1`

The reference pin shared by the Mobile Wallet Adapter packages advances to `protocol-kit@3.0.1`. The release is a JavaScript module-organization refactor — `startRemoteScenario` moves into its own module so React Native builds can exclude it — plus example-app and dev dependency bumps. No wire-protocol, API, or packaging surface the Dart port implements changed; see `docs/agents/upstream-audit-solana_kit_mobile_wallet_adapter-v3.0.1.md`.
