# Track `@solana-mobile/mobile-wallet-adapter-protocol-kit` `3.0.0`

The reference pin shared by the Mobile Wallet Adapter packages advances to `@solana-mobile/mobile-wallet-adapter-protocol-kit@3.0.0`. Upstream's 3.0.0 majors are JavaScript packaging changes (ESM-only build, `@solana/kit` 8 peer range, version-group realignment) with no Dart counterpart; the transport behavior this package implements was already equivalent to the upstream 3.0.0 runtime fixes. See `docs/agents/upstream-audit-solana_kit_mobile_wallet_adapter-v3.0.0.md`.
