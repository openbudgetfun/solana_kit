# Upstream audit — helius-labs/helius-sdk v3.3.0 → v3.4.0

`helius-sdk` v3.4.0 was published with ~2,500 lines of changes. This note maps every change to its Dart counterpart, including the items carried over from v3.3.0 that this release completes, so the compatibility claim can be audited.

Status: the workspace tracks `v3.4.0` (`checkedCommit 87cb392f0e69`); `clone:repos:status` verifies the pin.

## Ported

| Upstream change                                                     | Dart counterpart                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getAllTokenAccountsByOwner` reads the page from `value` (#380)     | `GetTokenAccountsByOwnerV2Response.fromJson` now accepts both page shapes: the flat result (accounts and cursor at the top level, sent with `withContext`) and the value-wrapped default (accounts under `value`, cursor as `paginationKey`). The port previously parsed only the flat shape, which the live endpoint does not return by default — pagination would have thrown on the wrapped shape. Covered by a two-page wrapped-shape pagination test.                                                                                                                                                                        |
| DAS `Interface` enum values corrected and extended (#373)           | `HeliusAssetInterface.legacyNft` wire value corrected from `Legacy_NFT` to `LEGACY_NFT`, and the `MplCoreGroup` / `MplBubblegumV2` interfaces added to the enum and its `fromJson` switch, with round-trip tests.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Parsed Events REST API (#356, `scan` in #379)                       | New `helius.parsedEvents` client with `parseTransactions`, `getTransactionHistory`, and `scan`, typed request/response models, manual `paginationToken` pagination, and the mainnet-only guard. `scan` models program/instruction/discriminator matches, mint matches, `scope`, `returnShape`, `budget`, and the `scan` summary (`stoppedOn`, counts, credits, `scannedThrough`). Covered by dispatch, pagination, scan-shape, and devnet-guard tests.                                                                                                                                                                            |
| Parsed Streams WebSocket client (#358)                              | New `helius.parsedStreams` client: `parsedTransactionSubscribe` with program/instruction/account-role filters and `full`/`matched`/`raw` details, automatic reconnect and resubscribe with exponential backoff, `onReconnect` reporting the close code and last delivered slot, buffered notifications, and `describeProgram` over the discovery endpoint. Covered by subscribe/unsubscribe, raw-detail, reconnect, discovery, RPC-error, and close tests.                                                                                                                                                                        |
| Preconfirmation filters and coverage RPC (#363, expanded in v3.4.0) | `PreconfWsClient.preconfSubscribe` now accepts a server-side `PreconfFilter` (status, region, account, signer, signature, and instruction filters with `includeSource`/deprecated `includeBam`) and `PreconfSubscribeOptions(slots: true)`. Slot bank-created/bank-frozen frames decode as `PreconfSlotNotification`; transaction-only subscribers keep the existing `notifications` stream. Each subscription uses its own connection, matching the upstream design because binary frames carry no subscription id. `getPreConfCoverage` reads the HTTPS endpoint. Covered by filter, slot-frame, coverage, and lifecycle tests. |
| `kitRpc` exposure (#377)                                            | `HeliusClient.kitRpc` is a standard `solana_kit_rpc` `Rpc` sharing the client's Helius URL, API key, and MEV Protect setting, so kit helpers can be passed the client directly. Covered by a `getSlot` round-trip test.                                                                                                                                                                                                                                                                                                                                                                                                           |
| MEV-protect support (#357)                                          | `HeliusConfig.mevProtect` appends `mev-protect=true` to the RPC and Sender URLs. Sender helpers accept a per-call override: `sendViaSender(mevProtect:)`, `TransactionsClient.sendTransactionWithSender(mevProtect:)`, and `SendBundleOptions.mevProtect`. Covered by URL and request tests.                                                                                                                                                                                                                                                                                                                                      |
| Broadcast expiry re-check (#368)                                    | `broadcastTransaction` now tracks landing with the upstream poll loop: it derives an expiry from the latest blockhash and chain height, polls `getSignatureStatuses`, and performs one final status read after the expiry height before throwing. `BroadcastTransactionOptions` exposes the offset, poll timeout, poll interval, commitment, preflight, and retry settings. Covered by confirmation, expiry re-check, and expiry-failure tests.                                                                                                                                                                                   |
| `filters.tokenTransfer` for `getTransactionsForAddress` (#381)      | `GetTransactionsForAddressRequest` now models the full v3 request surface: `transactionDetails`, `minContextSlot`, `encoding`, `maxSupportedTransactionVersion`, `paginationToken`, `sortOrder`, and `filters` with `status`, `tokenAccounts`, `tokenTransfer` (counterparty, direction, mint, raw amount bounds), `slot`, `blockTime`, and `signature` comparisons. Responses parse the live `{data, paginationToken}` shape (and the legacy `transactions` key).                                                                                                                                                                |
| Staking bigint constants (#372)                                     | `stakingU64Max` and `lamportsPerSolBigInt` expose the upstream `BigInt` values (`u64Max`, `LAMPORTS_PER_SOL_BIGINT`); `stakeStateLen` mirrors `STAKE_STATE_LEN`. The Dart staking client uses the HTTP staking API, so these are constants for callers rather than internal arithmetic.                                                                                                                                                                                                                                                                                                                                           |

## Already equivalent

| Upstream change                                                                                     | Why there is nothing to port                                                                                                                                          |
| --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Typed `HeliusRpcError` and null results returned as-is (#375)                                       | The Dart `json_rpc_client` already returns `json['result']` as-is (null included) and throws the typed `heliusRpcError` with the server's message on JSON-RPC errors. |
| Waiting-iterator rejection on connection drop (#362-era iterator behavior, further tests in v3.4.0) | The controller-based Dart WebSocket design ends awaiting iterators when the connection drops.                                                                         |
| Enhanced devnet baseUrl selection (#370)                                                            | The Dart `HeliusConfig` already routes the devnet cluster to `api-devnet.helius.xyz` explicitly.                                                                      |
| Lazy-namespace fixes (#378)                                                                         | JavaScript lazy-loading mechanics; the Dart port has no lazy namespaces.                                                                                              |
