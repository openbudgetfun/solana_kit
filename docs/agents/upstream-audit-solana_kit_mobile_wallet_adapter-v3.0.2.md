# Upstream audit — solana-mobile/mobile-wallet-adapter protocol-kit@3.0.1 → protocol-kit@3.0.2

`@solana-mobile/mobile-wallet-adapter-protocol-kit@3.0.2` was published with 35 commits across the monorepo (the same commit carries `@solana-mobile/wallet-standard-mobile@0.7.1` and `@solana-mobile/mobile-wallet-adapter-protocol@3.0.2`). Most of the release is dependency bumps, examples, and CI work. This note maps every behavioral change to its Dart counterpart, so the compatibility claim can be audited.

Status: the workspace tracks `protocol-kit@3.0.2` (`checkedCommit 2695142af520`); `clone:repos:status` verifies the pin.

## Ported

| Upstream change                                                                           | Dart counterpart                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fix(clientlib-ktx): stop waiting for the wallet when it returns RESULT_CANCELED (#1788)` | The commit also fixed the Java `LocalAssociationScenario` the Dart port mirrors: `start()` on a scenario that was already closed now rejects with `mwaSessionClosed` ("Scenario closed before it was started") instead of launching a fresh association, and the WebSocket connect-retry loop stops as soon as the scenario is closed instead of retrying until the connection deadline. Previously a Dart caller that closed a scenario while `start()` was connecting waited out the full retry schedule and deadline. Covered by closed-guard and close-during-connect tests. The Kotlin-side trigger (`startActivityForResult` returning `RESULT_CANCELED`) does not exist in Dart — the intent launcher is fire-and-forget — and the Java close-future deadlock the commit fixed inside the lock has no Dart lock to deadlock. |
