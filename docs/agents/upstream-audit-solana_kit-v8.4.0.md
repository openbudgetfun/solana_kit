# Upstream audit — @solana/kit v8.3.0 → v8.4.0

`@solana/kit` v8.4.0 was released on 2026-09-28. This note maps every change in that release to its Dart counterpart, including the items that are deliberately not ported, so the compatibility claim can be audited.

Status: the workspace tracks `v8.4.0`; `upstream:parity` passes against `@solana/kit@8.4.0`.

## Ported

| Upstream change                                                                                                                                                                                  | Dart counterpart                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SOLANA_ERROR__CODECS__SENTINEL_MISSING_AT_END_OF_BYTES` (8078028) (`@solana/errors`)                                                                                                            | `SolanaErrorCode.codecsSentinelMissingAtEndOfBytes` in `solana_kit_errors`, thrown by the sentinel decoder in `solana_kit_codecs_data_structures`                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `SOLANA_ERROR__CODECS__SENTINEL_MUST_NOT_BE_EMPTY` (8078029) (`@solana/errors`)                                                                                                                  | `SolanaErrorCode.codecsSentinelMustNotBeEmpty` in `solana_kit_errors`, thrown at codec construction in `solana_kit_codecs_data_structures`                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `SOLANA_ERROR__INSTRUCTION_PLANS__MESSAGE_REJECTED_BY_PACKER` (7618012) (`@solana/errors`)                                                                                                       | `SolanaErrorCode.instructionPlansMessageRejectedByPacker` in `solana_kit_errors`, documented for custom packers and honored by the planner in `solana_kit_instruction_plans`                                                                                                                                                                                                                                                                                                                                                                                          |
| Sentinel size strategy for `array`, `set`, and `map` codecs (#2061)                                                                                                                              | `SentinelArraySize` / `SentinelCountStrategy` in `solana_kit_codecs_data_structures`. All three collection codecs accept it; the sentinel is compared at item boundaries only, with `required`/`optional`/`omitted` strategies. Set and map delegate to the array codec, exactly as upstream.                                                                                                                                                                                                                                                                         |
| Message packer helpers (#2073): `resolveMaxInstructionsPerTransaction`, `assertMaxInstructionsPerTransaction`, `assertMessageCanAccommodateSize`, `isMessagePackerErrorThatRequiresNewCandidate` | `message_packer_errors.dart` in `solana_kit_instruction_plans`, exported from the package. The built-in packers, the transaction planner, and candidate selection route through them; the planner resolves the limit once per invocation and treats `instructionPlansMessageRejectedByPacker` as "open a new candidate message". Upstream deleted its internal `max-instructions.ts` in the same release; the Dart-only `resolveMaxInstructions` and `assertValidMaxInstructionsPerTransaction` (never exported upstream) were removed in favor of the merged helper. |
| `getReallocMessagePackerInstructionPlan` loop rewrite (#2071)                                                                                                                                    | The chunking loop in `solana_kit_instruction_plans` now mirrors upstream (`min(limit, remaining)` per chunk). Output is unchanged — the previous guarded form already produced the same chunks, including for exact multiples of the 10,240-byte limit.                                                                                                                                                                                                                                                                                                               |

## Not applicable in Dart

| Upstream change                                                               | Why there is nothing to port                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getShortU16Decoder()` malformed-input fix (#2067) (`@solana/codecs-numbers`) | The Dart decoder already guards against truncated buffers (`codecsInvalidByteLength` when the byte array ends prematurely), continuation chains longer than three bytes (`codecsNumberOutOfRange` when the shift exceeds 14), and out-of-range decoded values (`assertNumberIsBetweenForCodec` after each byte). These guards predate the upstream fix and are equivalent. |
| `getReallocMessagePackerInstructionPlan` 0-byte instruction (#2071)           | No behavior change was needed: the Dart packer never produced a 0-byte instruction for exact multiples of the 10,240-byte limit (the `lastInstructionSize != 0` guard predated the upstream fix). The loop was rewritten to upstream's simpler form purely to keep the sources aligned.                                                                                    |
