# Upstream audit — helius-labs/helius-sdk v3.4.1 → v3.5.0

`helius-sdk` v3.5.0 was published with six commits: two behavioral client features, one new beta API surface, its follow-up fix, a docs change, and the version bump. This note maps every change to its Dart counterpart, so the compatibility claim can be audited. The v3.4.0 → v3.4.1 delta is covered by `upstream-audit-solana_kit_helius-v3.4.1.md`; this PR advances the pin across both releases.

Status: the workspace tracks `v3.5.0` (`checkedCommit 9843aab33bb4`); `clone:repos:status` verifies the pin.

## Ported

| Upstream change                                                                 | Dart counterpart                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report disconnects with `onDisconnect` (#398)                                   | `ParsedStreamsClient` gains an `onDisconnect` callback carrying the same close code and last delivered slot as `onReconnect`. It fires once per outage, on the first close while subscriptions are open and after the connection state has settled — including when reconnect is disabled, the slow-consumer budget trips, or reconnect attempts are exhausted — and never for an explicit `close()`, when every subscription has already ended, or again for a drop inside the same outage. A throwing callback is swallowed. Covered by first-drop, no-refire-within-outage, close-does-not-fire, reconnect-off, and throwing-callback tests.                                                                                                                                                                                                                                                                                                                            |
| Add request signal, timeout, and host options (#399)                            | Parsed Events requests gain time limits and a host override. `HeliusConfig.parsedEventsUrl` replaces the Parsed Events base URL (a proxy's own query string survives next to `api-key`, because the client merges base query parameters), and `HeliusConfig.parsedEventsTimeoutMs` time-limits every request, rejecting with Dart's `TimeoutException` (upstream's `TimeoutError`). Each method also takes a per-call `timeout` that wins over the config default, mirroring upstream's per-call `AbortSignal.timeout`; a zero or negative duration disables the limit. Upstream's `AbortSignal` also carries external cancellation with a reason; Dart has no abort primitive in this workspace, so the port models the time-limit capability and documents the divergence rather than faking a signal. Covered by per-call, config-default, override-wins, and custom-host tests.                                                                                        |
| `getHistoricalAccountInfo` and `getHistoricalTokenAccountsByOwner` (#403, #405) | New beta Historical Account State reads on `helius.rpcV2`, with typed requests and responses: positional `[address/owner, query, config]` params where omitted query/config serialize as `{}` (a `null` slot is rejected by the server), `HistoricalAccountQuery` (`slot` / `slot` + `transactionIndex`), encodings (`base64`, `base64+zstd`, `jsonParsed`), data slices, `finalized`/`confirmed` commitments, `mint` or `programId` filtering (at most one), cursor pagination whose null `paginationKey` ends the scan (a short or empty page can still have one, since each call scans at most 25,000 accounts — the corrected limit from #405), and `value: null` meaning the account did not exist at that position rather than an error. Account `data` stays raw: a parsed object or an encoded `[data, encoding]` pair, matching upstream's open `parsed` shape. Covered by request-shape, null-value, non-transaction-write, page-parsing, and end-of-scan tests. |
| Clarify DAS `total` is the page item count (#401)                               | Documentation only upstream; the Dart DAS client models the same field and its docs were not wrong.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
